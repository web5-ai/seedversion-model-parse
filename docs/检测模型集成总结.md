### 3. Torchvision兼容性解决方案

#### 3.1 问题分析
- **问题**: torchvision 0.13.0+ 弃用了 `pretrained` 参数，改用 `weights` 参数
- **错误**: `UserWarning: The parameter 'pretrained' is deprecated`
- **影响**: ResNet等模型加载失败

#### 3.2 兼容性模块 (`models/torchvision_compat.py`)

**版本检测**:
```python
def is_new_torchvision():
    """检查是否为新版本的torchvision (>=0.13.0)"""
    major, minor, _ = get_torchvision_version()
    return major > 0 or (major == 0 and minor >= 13)
```

**兼容性包装**:
```python
def create_model_with_compat(model_func, use_pretrained=False, **kwargs):
    """使用兼容性参数创建torchvision模型"""
    if is_new_torchvision():
        # 新版本使用weights参数
        if use_pretrained:
            return model_func(weights='DEFAULT', **kwargs)
        else:
            return model_func(weights=None, **kwargs)
    else:
        # 旧版本使用pretrained参数
        return model_func(pretrained=use_pretrained, **kwargs)
```

**常用模型包装**:
```python
def resnet18_compat(use_pretrained=False, **kwargs):
    """ResNet18兼容性包装"""
    from torchvision.models import resnet18
    return create_model_with_compat(resnet18, use_pretrained, **kwargs)
```

### 5. 修复ModelLoader返回值问题

**问题**: `load_model` 方法没有返回值，导致测试脚本无法判断加载是否成功

**解决**: 添加明确的返回值:
```python
try:
    # ... 模型加载逻辑 ...
    logger.info(f"成功加载{model_name}模型")
    self.model.eval()
    logger.info("模型加载完成，已设置为评估模式")
    return True
except Exception as e:
    logger.warning(f"加载{model_name}模型失败: {str(e)}")
    return False
```
