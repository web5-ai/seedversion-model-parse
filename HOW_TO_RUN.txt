===================================
如何运行油菜籽成分分析系统
===================================

本项目提供了简单的运行脚本，可以从任何位置启动项目，自动设置正确的路径和环境变量。

方法一：使用批处理文件（Windows）
-----------------------------------
1. 双击 run_project.bat 文件
2. 系统会自动激活conda环境并启动项目

方法二：使用Python脚本
-----------------------------------
1. 激活conda环境：
   conda activate seed-parse

2. 运行Python脚本：
   python run_project.py

注意事项
-----------------------------------
1. 确保已安装所有依赖项：
   pip install -r requirements.txt

2. 确保conda环境已正确设置：
   conda env list
   应该能看到seed-parse环境

3. 如果遇到"No module named 'torch'"等错误，请确保在正确的conda环境中运行

4. 如果遇到路径问题，run_project.py脚本会自动处理，不需要手动设置路径

5. 项目启动后，可以通过浏览器访问：
   http://localhost:8000

常见问题
-----------------------------------
Q: 运行时提示缺少依赖项
A: 请按照提示安装缺少的依赖项，或运行：pip install -r requirements.txt

Q: 无法激活conda环境
A: 确保已安装conda，并已创建seed-parse环境：
   conda create -n seed-parse python=3.8
   conda activate seed-parse
   pip install -r requirements.txt

Q: 运行时出现路径错误
A: 使用run_project.py脚本启动，它会自动设置正确的路径
